# Arsip kerja (bukan bagian aplikasi)

Cabang ini hanya untuk menyimpan alat kerja dari sesi di cloud, supaya bisa dilanjutkan di MacBook. Tidak ditayangkan ke kader.

- `alat-uji/`: skrip pengujian otomatis (Playwright) dan data contoh palsu. `pantau_mock.py` = data contoh, `tk.py` = pengambil tangkapan layar.
- `sketsa/`: sketsa HTML dan PNG yang pernah dibuat.

Aplikasi sebenarnya ada di cabang `main`. Aturan kerja dan keputusan ada di dokumen proyek "Proyek Posyandu" (claude/preferensi-pengguna.md dan claude/status-penundaan.md).
